# Response to the Publication-Readiness Review

This document maps each point of the *Manuscript Publication-Readiness Review*
(Aug 5, 2026) to the change made in this revision. All numbers below were
regenerated by the supplied code and verified. Figures 4–7 and the real-data
tables were regenerated by the upgraded pipeline.

## 3. Definite errors (all corrected)

**3.1 — κ_SSR derived incorrectly as an amplitude factor.** Fixed throughout.
κ_SSR = 1/(1−R²_SS) is now presented as an **inverse residual-variance ratio and
variance-removal diagnostic**, explicitly *not* an amplitude-restoration factor:
the residual standard deviation scales as √(1−R²), and R²_SS pools superficial
variance, cortical–systemic covariance, noise, and short-channel cortical
sensitivity, so it cannot identify cortical loss. Updated in the abstract,
contribution list (item 2), Theory §2.2.6 (equation and both surrounding
paragraphs), Results, Discussion, Limitations, Conclusions (item 3), the table
captions, and code comments (`fnirs_kappa_group_analysis.py`,
`fnirs_kappa_realdata_analysis.py`). No reported amplitude changed from this fix
(κ_SSR was never applied).

**3.2 — Incorrect "post-SSR sensitivity" justification.** Removed. The text now
states that f_cortex is an optical-transport (Jacobian/Monte-Carlo) sensitivity
computed independently of the regression, so κ_PV "corrects the optical dilution
of the cortical component that survives SSR; it does not, and cannot, reverse
cortical signal that SSR has already subtracted." The claim that the surviving
residual is "recovered in full by κ_PV" was deleted wherever it appeared
(§2.2.6, Results, Discussion).

**3.3 — Scalar correction not generally exact.** Added the governing
wavelength-domain matrix form ĉ = E⁻¹ P⁻¹ F⁻¹ y_SSR (new Eq. for the matrix
correction) with P, F wavelength-diagonal; the scalar κ_PV / κ_applied are now
explicitly described as *descriptive summaries*, and the text notes the code
applies F⁻¹, P⁻¹ per wavelength before inversion.

**3.4 — Synthetic paradigm vs. dataset.** Corrected. The dataset is now described
accurately (three conditions — left/right tapping + control — 30 trials each,
5 s, irregular ~25–40 s inter-onset intervals; verified from the events files).
The synthetic 5-on/5-off design is stated to be an *idealized testbed, loosely
inspired by but not a matched reproduction* of the experiment, and the note that
its 0.1 Hz block rate sits at the filter edge is added. The single-channel demo
wording was likewise softened.

## 4. Major scientific / reproducibility concerns

**4.1 — Self-consistent synthetic validation.** A new Limitations paragraph
states plainly that the synthetic validation tests algebraic self-consistency and
noise propagation (generator and inverse share the same f_cortex), not
independent accuracy in real anatomy, and specifies the stronger
realistic-mesh / localized-activation test as future work.

**4.2 — Monte-Carlo uncertainty & provenance.** New production driver
`mc_uncertainty.py` computes f_cortex for **both wavelengths** with the same
anisotropic (g = 0.9) transport, over **multiple independent seeds**, reporting
mean ± SD, bootstrap CI, **effective sample size N_eff = (Σw)²/Σw²**, and
**per-SDS weighted DPF**, and writes raw JSON/CSV (in `results/`). New
Supplementary Table (MC uncertainty) reports these; N_eff falls 641→60 (760 nm)
with SDS, DPF ≈ 6.4–6.8 (760) / 5.2–5.3 (850). The wording "9×10⁵ photons per
separation" is contextualized (one ensemble binned into annuli; N_eff makes the
effective count explicit). The adopted f_cortex table lies within the MC band.

**4.3 — CSF ratio recomputed with consistent anisotropic transport.** γ is now
computed with the *same* g = 0.9 Henyey–Greenstein transport as the two-layer
model, over multiple seeds and **three CSF thicknesses** (1/2/3 mm). At the
nominal 2 mm: γ = 1.85, 1.75, 1.71, 1.48 (25/30/35/40 mm), consistent with the
earlier isotropic estimate within MC uncertainty — so the CSF ratio is robust to
the anisotropy assumption. Table 3 (CSF) updated with the anisotropic values, the
missing **40 mm row added**, and γ SDs shown. The outcome-guided justification
("keeps the recovered amplitude physiological") was removed from the code and
replaced with a physical justification; physiological plausibility is now stated
to be an external sanity check only.

**4.4 — In-vivo analysis upgraded.** New `fnirs_kappa_realdata_v2.py` implements:
per-channel SDS and per-channel f_cortex; TDDR motion correction + SCI (<0.5)
channel rejection; **nearest** short-channel SSR regressor (not the global mean);
condition-resolved **contralateral** channel selection (validated by observed
lateralization); and a fixed pre-registered **window-mean** estimator (not a
positively-biased max). Regenerated group result (N = 5): contralateral HbO₂
**0.124 → 0.843 ± 0.307 µM** (~7×), HbR −0.047 → −0.319 µM, per-channel κ_PV 6.34,
κ_SSR(760/850) = 1.78/2.34. Tables 5–6 and Figures 4–7 regenerated accordingly.

**4.5 — 38 mm rule reframed as noise-conditional.** The operating regime is now
stated as noise-dependent: σ_OD = 10⁻³ is held fixed across SDS (a simplification;
real shot noise grows with separation), the crossover is instrument-dependent, and
the general statement is a 2-D SDS-versus-noise operating map rather than a
universal cutoff. Applied in §Operating regime, Limitations, and the abstract.

## 7.3 Positioning

A framing sentence was added to the Conclusions positioning the paper as a
reproducible *methodological* study (numerical ill-conditioning at low SNR,
spectral-quadrature bias, model-uncertainty propagation, transparent
wavelength-specific OD correction), rather than a claim of a universal correction.
